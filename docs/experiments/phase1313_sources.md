# Phase 13.13 English Foundation Sources

The Phase 13.13 corpus uses English UTF-8 plain-text works retrieved from Project Gutenberg. The source pages identify the language as English and provide the official ebook identifiers and plain-text endpoints.

The Project Gutenberg license page explains that many individual works are unrestricted under U.S. copyright law, while some works may carry additional restrictions; each source's embedded license notice must be retained or otherwise handled according to the applicable terms. The corpus preparation manifest records the source identifiers, URLs, raw SHA-256 hashes, cleaned SHA-256 hashes, and the selected train/validation split.
